# 当前演示流程

main最终版的实现已经替代原“待机两页循环、第一讲后插入两张图、底部字幕”规划。当前使用开机三种尺寸实验图、完整课程自动链、顶部中文字幕，保持一个连续系统。离线结果见[验证记录](VALIDATION.md)，下列现场效果仍需实板确认。

| 环节 | 操作和表现 | 要求对应 |
|---|---|---|
| 三种尺寸实验图 | 开机WIDE01→TALL01→SMALL01，每页7秒；观察比例、黑边、前后按钮；KEY2暂停或继续自动演示 | 扩展3缩放、扩展2自动切换 |
| 待机与课程入口 | WAIT01/WAIT02各4秒，COURSE2秒，随后进入第一讲 | 基础1完整流程、扩展2轮播 |
| 三段讲解 | 音频消费结束后自动进入下一讲，重播或手动操作仍可用 | 基础3音频、音视频联动 |
| 声音观察 | 选择纯音、钢琴、人声，对照波形和左右电平；KEY4切换触发；每段约4秒，必要时重播 | 扩展5可视化 |
| 参数调节 | 打开设置，调整亮度/对比度、音量与静音，观察右侧常驻数值/变化提示 | 扩展4实时调节 |
| 三题答题和成绩 | 自动演示到题目停住，选择答案并提交；解释页4秒后自动进入下一题；最后显示成绩 | 基础1、扩展1图层、计分交互 |
| 通知与返回 | 课程中插入普通或优先通知，退出恢复原上下文；物理优先开关需释放 | 多源信息融合、插播控制 |
| 回到开头 | KEY15返回第一张实验图，恢复默认自动流程 | 系统闭环 |

顶部1280×40中文标语贯穿画面，右侧中文状态栏常驻；左侧显示触发/自动演示状态。通知是校园终端公共信息功能，不强行作为声音教学内容。

KEY2在课件中控制自动跳页，不暂停音频；设置菜单、通知、加载期间不自动跳页。自动到第一题不等于自动作答。讲解链中途改变音源、开菜单或进入通知会影响实际演示时间，因此不把整场宣称为固定时长。

现场优先用“缩放三页→讲解→观察波形和参数→答题→通知返回→成绩”展示。持续运行、异常卡/文件、不同显示设备、声音和画面连续性另做验收，不用一段短演示替代稳定性测试。
