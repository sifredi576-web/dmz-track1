# 声音课件演示补齐方案

2026-11-02。状态：规划，尚未实施。本方案只补齐不同尺寸图片展示、课件字幕/状态栏、待机自动轮播，沿用现有声音课程、答题、通知和音视频链路。

条款对应选题一1.4的五项扩展、1.5的四项基础要求。当前已验证基线见[迁移记录](VALIDATION.md)，本文不代表新功能已经通过验证。

## 1. 演示流程

全程约5～6分钟，在同一套课件中完成。

| 环节 | 现场操作与画面 | 展示要求 |
|---|---|---|
| 待机，约20秒 | 实验室介绍、课程预告两页每6秒轮换；底部提示按确认开始 | 扩展1：滚动提示；扩展2：自动轮播与擦除转场 |
| 开课，约40秒 | 任意待机页确认进入课程，显示第一讲并播放讲解 | 基础1：完整应用流程；基础3：HDMI音频 |
| 实验图浏览，约40秒 | 第一讲之后查看横向声波示意图、竖向实验装置图，按键前后切换 | 扩展3：不同分辨率的缩放与留边；扩展2：切页转场 |
| 画面设置，约20秒 | 在实验图上打开设置，调整亮度、对比度后恢复默认 | 扩展4：画面变化与OSD参数同步 |
| 声音观察，约60秒 | 完成其余讲解，选择纯音、钢琴、人声；调整音量、静音和暂停 | 扩展5：实际PCM波形、电平；字幕栏显示播放状态 |
| 答题与插播，约60秒 | 选择答案并提交；在答题中触发通知，再退出返回原页面 | 扩展1：焦点、答案、成绩叠加；创新：计分和上下文恢复 |
| 总结，约20秒 | 显示成绩，返回待机，恢复两页轮播 | 完整闭环 |

通知是实验室终端的公共信息功能，不作为声音课程的教学内容。常规演示使用普通通知，优先通知及物理开关另作补充检查。

## 2. 不同尺寸图片：先把现有缩放展示出来

现有BMP解码器已经支持等比最近邻缩放和居中留边，但当前课件背景全部为640×480，演示缺少对比。

新增两个课程页面，接入顺序为：

`LESSON01 → IMG_WIDE → IMG_TALL → LESSON02 → LESSON03 → OBSERVE`

| 页面 | 原始BMP | 当前算法的输出 | 教学内容 |
|---|---|---|---|
| IMG_WIDE | 1280×720，24位 | 640×360，上下各留60像素 | 声波传播、振动与时间关系示意 |
| IMG_TALL | 360×640，24位 | 270×480，左右各留185像素 | 音叉或扬声器实验装置及观察步骤 |

- 图片保留原始分辨率写入TF卡，由FPGA读取BMP头并缩放；不在电脑端统一转成640×480。打包器同步更新文件长度、资源记录及CRC，不能只替换卡内BMP。
- 页面只展示实验图和必要图注，不把原有整页课件压成竖图。图中加入圆形或方格作为比例参照，现场可观察是否变形。
- 导航与状态栏由FPGA独立叠加，不跟随图片缩放。实验图页单独使用32像素高的导航按钮：横图放在`y=424～455`的下方留边，竖图放在左右留边；需要配套制作相同尺寸的按钮贴图。竖图底部32个源像素留空白，保证底栏不挡实验内容。
- 每页明确标注原始尺寸及“等比适配”，便于说明处理过程。正文和图注可以制作进原图，但不能把它们称为实时字幕。
- 第一版保留全屏等比适配。将任意图片缩放进“左图右文”的指定矩形，需要扩展缩放器和页面描述，列为后续优化，不作为此次完成条件。

## 3. 课件字幕与状态栏：操作结果持续可见

在输出画面底部预留一行，建议范围为`y=464～479`；现有普通页面按钮截至`y=463`，两者不重叠。新增实验图页按上一节单独排布导航。

- **固定状态**：运行计时、播放/暂停、静音、音量。计时明确为设备运行时间，不显示成真实日期时间。
- **滚动提示**：待机显示开始操作；课程显示翻页/重播提示；观察页提示选择音源；答题页提示“选择后提交”；通知页提示退出或等待解除。
- 第一版复用现有OSD字库与滚动逻辑，采用现有字库支持的简短英文和数字；中文正文继续由课件素材呈现。新增中文滚动字库另行评估。
- 菜单打开时由设置OSD接管显示；退出菜单恢复课件底栏。通知期间显示通知提示，退出后恢复课程提示。
- 在顶层只开放这条课件底栏，不直接打开整套旧图库OSD，避免旧标题、文件信息遮住课件。字符与遮罩沿用现有像素流水，检查边界和延迟对齐。

涉及`dmz_osd.sv`及顶层叠加选择；播放状态取现有控制信号，页面提示取已提交页面状态，加载期间不提前显示下一页提示。

## 4. 待机轮播：优先使用已有配置能力

配置打包器及`dmz_scene_runtime`已经支持`auto_target`、`dwell_ms`。当前声音课件未设置它们，不需要另写一套图库轮播控制器。

- WAIT01设置`auto_target=WAIT02`、`dwell_ms=6000`；WAIT02反向设置，形成两页循环。
- 两页的开始按钮都直接进入COURSE，不再要求先从WAIT01点到WAIT02。进入课程后仅待机页具有自动目标，讲解、实验图和答题页保持手动操作。
- 第一版待机采用无音频轮播，解除WAIT01现有BGM绑定，避免每次翻页重启或切断背景音乐；HDMI音频在课程讲解及观察页充分展示。
- 复用现有帧提交和擦除转场；驻留时间从新画面完整呈现后开始计算。
- 补齐“设置菜单打开时停止待机计时及自动跳页”的保护；通知期间保持现有暂停轮播行为，返回待机重新计时。确认开始与到时跳页相遇时，人工操作优先。

## 5. 实施顺序与改动范围

| 顺序 | 工作 | 主要位置 |
|---|---|---|
| 1 | 制作两张原尺寸实验图，增加页面、前后跳转及待机自动目标，重新打包 | `assets/course.json`、素材与打包工具 |
| 2 | 接入课件底栏，增加页面提示及播放状态，调整遮罩区域 | `rtl/video/dmz_osd.sv`、`rtl/top/dmz_track1_top.sv` |
| 3 | 补待机菜单保护及操作优先级；检查加载、通知、返回时的轮播行为 | `rtl/control/dmz_scene_runtime.sv`及相关测试 |

现有原始课件PNG/SVG不全，实施前须确认可编辑素材来源；可另制新增实验图。已打包资源能够用于对照，不能冒充原始设计稿。新增页与控件仍须符合现有32页、64资源、128控件等上限。

## 6. 验收与完成标准

1. **缩放**：两种原始尺寸确实从卡读取，比例、留边、方向正确；导航和底栏不遮挡有效内容。复用逐像素缩放检查，补新页面资源绑定检查。
2. **字幕**：正常课件中持续可见，时间、音量、暂停和静音随操作变化；滚动无越界，菜单及通知进出后显示正确。
3. **轮播**：连续轮换至少两轮；任意待机页均能开始课程；菜单、通知和加载中不误跳，教学和答题不会被待机计时打断。
4. **工程与实板**：做相关仿真、一次完整构建，再按第1节上板演示；稳定性另安排持续运行及异常素材检查，不能用5分钟演示代替。

现有基线为16089 LUT、8844寄存器、62 BRAM9K、20 DSP，setup/hold余量为+0.266/+0.030ns。优先复用现有存储和绘制逻辑，完成后记录实际资源及最终时序，不以新增功能为理由直接接受不明退化。基础4“工程规范性”通过清晰的唯一工程、约束、测试与验证记录体现。
