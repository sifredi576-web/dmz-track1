## 统一工程入口

当前顶层：`rtl/system/dmz_track1_top.sv`。生成的 TD 工程：`build_system/dmz_track1.al`。

```powershell
# 在 dmz_track1 目录运行
./scripts/project.ps1 -Action Test
./scripts/project.ps1 -Action Build
./scripts/project.ps1 -Action Download
./scripts/project.ps1 -Action Status
./scripts/project.ps1 -Action Mute
./scripts/project.ps1 -Action Tone
./scripts/project.ps1 -Action Reload
./scripts/project.ps1 -Action Smoke
./scripts/project.ps1 -Action Soak -Seconds 1800
```

默认自动查找唯一的CH340；若有多块设备，用 `-Port COM3` 指定。一次仅运行一个串口工具，长测期间不要用另一个脚本占用同一串口。运行Test/Build不下载，Download只配置SRAM。

默认静音。Tone持续发声直到Mute、Reload或重下载；Smoke仅短暂发声，结束/失败时尝试恢复静音；Soak始终静音。无需拨动SW1。物理SW0仍控制运行/复位。

旧 `set_audio_mode.ps1` 和 `build_audio_test` 仅保留为历史测试；后续统一使用本页入口。新脚本在同一串口连接内发送明确的字节数组并等待板端回报，已经实板通过；旧脚本故障的唯一根因尚未证实。

## 工程结构

| 层次 | 当前模块 | 后续职责 |
|---|---|---|
| 时钟与板级适配 | `dmz_p2_pll`、ADC/SDC、SDRAM硬宏、serializer | 保持已核对的DMZ引脚和多时钟复位 |
| 存储底层 | `dmz_sd_reader`、`dmz_spi_byte`、`dmz_sdram_ctrl`、BIST | SD只读/CRC、刷新、突发与错误诊断 |
| 资源与帧缓存 | `dmz_bmp_loader`、`dmz_image_framebuffer`、`dmz_pixel_fifo` | 演进为共享FAT服务、图像加载和预取调度 |
| 音视频输出 | `hdmi_core`、`dmz_tone` | 加入WAV/音量、视频处理、字幕和可视化 |
| 统一控制 | `dmz_media_control` | 默认静音；U/M/B/S/R；后续播放状态机和交互 |
| 诊断 | `dmz_status_cdc`、`dmz_status_uart` | 跨域一致快照、命令回报、欠载/文件错误计数 |

不再复制一套SDRAM/HDMI到各新功能工程中。阶段文件夹内已有的底层模块继续共享；统一顶层是后续板上集成入口。

## 诊断包 T1ST v2

115200/8N1，64字节、小端、约0.5秒一包，第15字为前15字XOR。与P3ST/AVST历史格式分开识别。

| 32位字 | 含义 |
|---|---|
| 0 | magic 0x54533154，即T1ST |
| 1 | 低8位版本2；8初始化、9 BIST完成、10 BIST通过、11显示有效、12前台bank、13欠载、14帧缓存故障、15 PLL锁定、16静音、17 SW1、18提示音相位、19 SW2、21:20音频模式 |
| 2～5 | 采样使能、PCM包、首个立体声子采样非零的PCM包、ACR包计数 |
| 6～7 | CTS；高16位N=6144/低16位采样率48000 |
| 8～10 | BIST错误、转换像素、欠载像素 |
| 11 | 从高字节依次为SD错误、图片错误、SD状态、图片状态 |
| 12～14 | BIST核对字数；刷新次数；高16位命令计数/中8位最近命令ASCII/低8位保留 |
| 15 | XOR |

内存域状态通过请求/应答及保持总线跨到像素域；新CDC测试使用两个异步时钟检查关联字段不撕裂。软件R命令重置媒体流水线，不重置PLL、命令接收器或诊断发送器，因此可以观察重新初始化过程。
