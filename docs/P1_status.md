## 使用
工程：`build_p1/dmz_p1.al`；位流：`build_p1/dmz_p1_Runs/phy_1/dmz_p1.bit`。
在 dmz_track1 目录运行：
```powershell
./scripts/build_p1.ps1
./scripts/test_p1.ps1
& D:/ANLU/bin/td_commands_prompt.exe scripts/download_p1.tcl
./scripts/test_uart.ps1 -Port COM3
```
下载仅配置 SRAM，掉电失效。P0 工程单独保留。

| 控制 | 行为 |
|---|---|
| SW0=高 | 运行；低电平复位 |
| SW1=低 | 播放测试音；高电平静音 |
| SW2=低 | 八色竖条 + 底部灰阶；高电平切换 RGB 渐变 |
| LED0 | 心跳，约 0.67 秒完整周期 |
| LED1 | PLL 锁定 |
| LED2 | 复位释放/运行 |
| LED3 | 静音状态，亮表示静音 |

## 视频、音频规格
- 50 MHz 输入，PLL 产生 25 MHz 像素时钟、125 MHz 串行时钟；ODDR 输出 250 Mbit/s 每通道。
- 有效区 640×480，总时序 800×525，实际刷新约 59.524 Hz。
- 25 MHz 是随板例程使用的时钟，不是精确的 VGA 25.175/25.2 MHz；接收器兼容性以实测为准。当前用户已确认能显示。
- 48 kHz、16 位、双声道相同的 1 kHz 正弦；幅值 4095，约 -18 dBFS。
- 使用像素域分数采样使能，间隔 520/521 周期；不在逻辑中另造音频时钟。
- HDMI ACR：N=6144，稳态 CTS=25000，由实际像素/采样节拍测量。
- 发送 AVI、SPD、Audio InfoFrame，以及音频采样包和 BCH 校验。

## 硬件核对
依据综合底板原理图 `微处理器原理综合设计底板/EG4S20_综合底板.pdf`，以及随板 `M0_Borad.zip/10_VGA_hdmi_tx_display_MB` 例程。

| TMDS | P 引脚 | N 引脚 |
|---|---|---|
| CLK | P1 | R1 |
| D0 | N1 | M1 |
| D1 | P4 | N4 |
| D2 | J3 | J4 |

采用随板例程的 LVDS33 约束；TD 引脚报告确认自动生成了对应负端，并把 ODDR 打包进 IO。
底板 HDMI 的 DDC/HPD 没有接到 FPGA，不能读 EDID 或检测热插拔；当前固定模式输出。不要据此宣称全部 HDMI 电气规范认证。

## 验证证据
- `p1_sim_result.txt`：3 帧、2419 个采样使能、1259998 个串行符号逐位通过；50 个 ACR、604 个 PCM 包、AVI/SPD/Audio InfoFrame 各 4 个。
- 2416 个已打包立体声采样中，1544 个非零；测试后半程主动静音，因此剩余零值符合预期。
- 验证有效像素数、采样间隔、48 点正弦周期、双声道及位对齐、PCM 奇偶校验/有效位、头及子包 BCH、InfoFrame 校验和、ACR N/CTS、静音与复位恢复。
- 仿真使用行为 PLL/ODDR 模型；不模拟模拟锁相环、电缆、电气完整性或接收器音频解码。
- `build_p1/dmz_p1_Runs/phy_1/dmz_p1_pr.timing`：建立裕量 +5.592 ns，保持裕量 +0.018 ns，STA 覆盖 99.94%。
- `p1_cross.timing`：pixel_clk→serial_clk 共 55 个端点，建立 +6.097 ns，保持 +0.018 ns，无违例。工具默认汇总的 CC 标记不能代替这份显式跨时钟报告。
- 异步开关/UART 输入及 LED/UART 输出做了时序例外；外部 HDMI 接收时序与板级信号完整性仍需实测。
- 资源：1059 LUT、369 普通寄存器、5 BRAM9K、1 DSP、1 PLL；IO 寄存器另列于报告。
- `p1_download_log.txt`：JTAG 校验 EG4S20BG256，5 MHz SRAM 下载完成。
- `p1_uart_test.txt`：下载后 COM3，115200 8N1，256/256 字节回环通过。
