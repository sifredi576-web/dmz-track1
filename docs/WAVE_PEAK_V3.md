# 波形峰顶与连续性V3：单项验收

用户已认可V2大小，授权本轮只优化峰顶和连续性。显示框仍为(64,128)、512×160，音量及按钮不变。触发稳定（左侧按钮）和状态界面（右侧）必须在前项合格后再询问，本版未实现。

已检查本地TONE01.WAV：约440Hz，PCM范围±8231，未据此发现硬削顶。旧显示每16样本取点，48kHz下显示采样3kHz，440Hz每周期约6.8点，先取8位、换算像素再插值，会产生折角与过早量化。

本版每8样本取点，显示采样6kHz，每周期约13.6点；128点时间窗从约42.7ms缩短至21.3ms，因此同一频率横向周期显示更宽。缓存保留12位幅度，插值后才换算像素（无符号偏移二进制运算）。音频仍48kHz，显示采集不反压音频。保持半开线段、单像素平段及双缓冲帧消隐交换。

这不是触发锁定、抗混叠滤波或曲线拟合；起点仍可能漂移，屏幕像素仍有量化限制，不承诺消除所有平段。
