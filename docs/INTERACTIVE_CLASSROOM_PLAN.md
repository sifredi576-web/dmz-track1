# 物理实验室交互教学与信息发布终端方案

日期：2026-11-01。状态：拟实施方案，尚未开发或验收。基于现有DMZ_EG4S20单板多媒体工程继续扩展。

## 1. 应用定位

终端安装在学校物理实验室，通过HDMI连接带声音输出的显示设备。日常轮播课程安排；上课时展示图文课件、播放讲解并进行声音观察和按键答题；管理员发布通知时，优先展示通知，结束后返回原教学步骤。

首个示范课程为“声音与音色”。声音观察属于课程内容；应急通知属于实验室公共终端的运行功能，不编入教学知识或答题内容。整机共用一个工程、一套界面与音视频链路。

依据：[赛题原文](<D:/learning/FPGA/全国大学生嵌入式芯片与系统设计竞赛'2026FPGA赛道选题指南-安路科技.pdf>)，选题一，PDF第14—15页。应急信息发布是1.2列出的应用场景，不是1.4的五项扩展要求之一。

## 2. 第一版范围与完整流程

第一版实现一节课、三段声音样本、三道单选题、普通通知和应急通知两种插播。实验对象为TF卡中的声音样本，不增加麦克风或外部信号采集硬件。

| 环节 | 内容与操作 | 结束条件 |
|---|---|---|
| 待机 | 轮播课程安排、实验室介绍，播放背景音乐 | 用户从菜单选择课程 |
| 课程封面 | 显示“声音与音色”、学习目标和操作提示 | 确认开始 |
| 图文学习 | 三页依次说明声音、音调、音色，分别播放对应讲解 | 手动翻页；自动模式等待讲解播完再前进 |
| 声音观察 | 在同一页面选择纯音、钢琴、人声三段样本，显示实际输出PCM波形及左右电平 | 用户确认进入答题 |
| 课堂答题 | 显示三道题，按A/B/C/D对应按键作答；显示正确答案和解析 | 查看解析后确认下一题 |
| 课程总结 | 显示首次作答正确数和完成状态 | 重新学习或返回待机 |

示例题包括“选择刚才播放的声音来源”“比较两段素材的音调高低”“识别同音调的不同音色”。判断依据为预设答案，系统不自动分析音色、识别人声或计算频谱。

讲解音轨单次播放，播完停在当前页；声音观察样本循环播放。暂停、静音和音量控制贯穿整节课。每题仅首次提交计分，重复确认不重复加分；重新学习清零成绩。

## 3. 通知插播与恢复

优先级为：应急通知 ＞ 普通通知 ＞ 教学 ＞ 待机。

| 通知类型 | 进入与显示 | 确认、解除与恢复 |
|---|---|---|
| 普通通知 | 管理员通过预留板载操作或UART命令触发，展示停课、设备维护等通知页 | 确认后关闭，返回原页面 |
| 应急通知 | 沿用现有应急开关或命令入口，展示应急页面及提示音，暂停课程操作 | 确认仅标记已读；管理员解除事件后才能退出 |

插播前保存课程步骤、声音样本选择、答题记录、暂停、静音和音量状态。退出后恢复原教学页面；第一版讲解或样本从头播放，并恢复原暂停、静音和音量状态，不实现精确音频断点续播。

应急物理开关仍有效时，确认或普通退出操作不得解除应急状态。应急覆盖普通通知时只保留一份原教学上下文，解除后直接回到教学，不形成多层通知堆栈。原有应急提示音继续遵守静音和音量设置。

演示时由管理员模拟触发事件，用于展示终端插播与恢复能力，不计入课程成绩。

## 4. 功能与赛题条款逐项对应

| 系统功能及演示位置 | 对应条款 | 完成或展示依据 |
|---|---|---|
| TF扫描、BMP解析、课件选择、自动/手动播放 | 1.3赛题要求；1.5基础（1）核心功能完整性 | 从卡中选择课件并正常显示、切换 |
| SDRAM缓存与HDMI持续显示 | 1.3赛题要求；1.5基础（2）显示稳定性与鲁棒性 | 连续播放、频繁切换、暂停恢复和异常素材测试，不能只凭短时演示判定 |
| 讲解、声音样本及背景音乐经HDMI输出 | 1.5基础（3）基础音频输出 | 显示设备实际发声，暂停、静音、音量正常 |
| 唯一主工程、模块划分、约束、仿真、编译与验证记录 | 1.5基础（4）系统工程规范性 | 工程文件和证据审查，不对应一个界面按钮 |
| 章节、页码、运行计时和滚动提示叠加 | 1.4扩展（1）图层叠加与字幕效果 | 图片上叠加动态信息；运行计时不标为真实日期时间 |
| 待机轮播、课件翻页使用现有擦除转场 | 1.4扩展（2）图片切换与转场特效 | 正常翻页展示连续转场；应急页优先及时呈现 |
| 不同尺寸的横向课件与竖向实验图自适应显示 | 1.4扩展（3）图片缩放适配 | 展示至少两种尺寸和方向，图像保持比例、居中留边 |
| 按键调节亮度、对比度，并显示参数值 | 1.4扩展（4）实时调节与信息叠加 | 在课程设置菜单调整，画面和参数同步变化 |
| 声音观察页叠加实际PCM波形及声道电平 | 1.4扩展（5）音频可视化表现 | 切换样本、静音或调整音量后可视化随实际输出变化 |
| 图文讲解绑定、答题计分、通知抢占和状态恢复 | 自主创新，非五项明确扩展 | 完整演示课程流程、通知插播及返回 |

所有运行时解析、调度、答题、绘制和音视频处理由FPGA完成，遵守1.3关于不使用额外处理器的要求。课件素材制作属于开发准备工作。

## 5. 界面、操作与素材

教学界面统一为顶栏“课程/步骤/页码”、中央“课件或题目”、底栏“字幕/播放状态/操作提示”。声音观察页在中央增加波形区域；画面设置以菜单叠加。通知状态复用同一显示链路，覆盖教学内容。

以下为拟新增交互规则，现有按键操作仍以[USER_GUIDE](D:/learning/FPGA/dmz-track1/USER_GUIDE.md)为准：

- 菜单提供课程开始、上一步/下一步、声音样本、画面设置、素材浏览和退出课程；素材浏览保留现有BMP/WAV分类与选择能力。
- 答题态建议将KEY15～KEY12解释为A/B/C/D；该状态屏蔽同一组按键原来的亮度、对比度命令，避免一次操作同时答题和调图。
- 保留暂停、静音和音量入口；通知态屏蔽课程翻页与答题。每个页面明确显示可用操作。

| 素材组 | 建议短文件名 | 数量 |
|---|---|---:|
| 待机与封面 | WAIT01.BMP、WAIT02.BMP、COURSE.BMP | 3张 |
| 课程与观察页 | LESSON01～LESSON03.BMP、OBSERVE.BMP | 4张 |
| 题目与解析 | QUIZ01～QUIZ03.BMP、EXPL01～EXPL03.BMP | 6张 |
| 总结与通知 | RESULT.BMP、NOTICE.BMP、ALERT.BMP | 3张 |
| 讲解、样本与背景音乐 | LECT01～LECT03.WAV、TONE01.WAV、PIANO01.WAV、VOICE01.WAV、BGM01.WAV | 7段 |

共16张BMP、7段WAV，处于现有32张图片、16音轨上限内。中文正文、题目和解析先制作进BMP；页码、成绩、参数等动态内容使用现有OSD字模。BMP保留现有24/32位BI_RGB范围；WAV采用48kHz、16位、双声道PCM；HDMI输出保持640×480。

资源按8.3短文件名绑定，启动时通过目录查询解析为内部索引，不能依赖文件复制顺序。缺少某项资源时显示缺失文件提示并禁止启动对应步骤，不用错误索引播放其他素材。

## 6. 实现结构及已有/新增边界

现有能力及验证范围见[架构说明](D:/learning/FPGA/dmz-track1/docs/ARCHITECTURE.md)和[验证状态](D:/learning/FPGA/dmz-track1/docs/VALIDATION.md)。以下模块是计划，不代表已存在。

| 部分 | 实施方式 |
|---|---|
| 媒体底座：已有 | 复用FAT/SD读卡、BMP/WAV解析、帧缓存、缩放、转场、HDMI、音量、可视化；保留现有时钟域 |
| 课程控制：新增 | 在control层增加课程状态机及只读步骤表，记录页面、音轨、播放策略、题号和下一步骤 |
| 答题控制：新增 | 小型答案表、首次提交锁定、成绩寄存器；结果输出给OSD和课程控制 |
| 通知调度：扩展 | 在现有scene控制基础上增加普通通知、优先级和一份返回上下文；物理应急保留最高优先级 |
| 播放联动：新增 | 页面呈现稳定后开始对应讲解；增加单次播放策略及实际播放完成事件，区分解码到文件末尾与FIFO中的声音真正播完 |
| 界面与命令：扩展 | 增加课程状态、页码、分数和操作提示；按当前状态解释按键，确保每次操作只执行一个动作 |

课程控制发出统一的页面、音轨和播放请求，不直接操纵SDRAM或HDMI时序。异步读卡和切页结果应带步骤标识或失效标记，避免插播后旧请求完成又把通知页覆盖。第一版步骤表固化在FPGA内，后续可扩展为TF配置文件。

## 7. 开发顺序与验收

| 阶段 | 交付内容 | 通过条件 |
|---|---|---|
| 1. 素材与课程骨架 | 文件名绑定、封面和三页课程、手动前进/返回 | 素材顺序变化不影响绑定，缺失资源有提示 |
| 2. 图文语音联动 | 页面与讲解绑定、单次播放、重复讲解、暂停恢复 | 新页稳定后播放正确音轨，播完停页，无旧页声音串入 |
| 3. 声音观察 | 三段样本选择、实际PCM波形和电平 | 样本、声音、可视化对应，静音与音量效果一致 |
| 4. 答题闭环 | 三题、解析、首次计分、课程总结 | 重复按键不重复计分，重学能清零，按键不误调参数 |
| 5. 通知插播 | 普通/应急通知、优先级、上下文恢复 | 从讲解、答题或加载中均能插播；解除后回到正确步骤 |
| 6. 整机验收 | 五项扩展逐项演示、异常素材和持续运行 | 功能仿真、资源/时序检查及实板显示听音分别留记录 |

每阶段记录LUT、寄存器、存储和时序变化；新增功能保持既有显示频率、采样率和处理吞吐。对纯整理性改动做同配置性能对照，避免重复出现等价写法引起的退化。当前基准记录为15503 LUT、7561寄存器、setup/hold余量1.950/0.021ns；新增功能的资源预算须另行评估。

现场演示约5～8分钟：待机轮播 → 开课并翻页 → 横竖图缩放和转场 → 调节亮度/对比度 → 三段声音观察 → 答一道题 → 插播通知 → 解除后回到原题目 → 完成并显示成绩。通知插播只用于证明终端的公共信息服务能力。

本文件只定义后续方案；不改变现有需求裁定，不作为新增功能已经实现或实板通过的证明。
