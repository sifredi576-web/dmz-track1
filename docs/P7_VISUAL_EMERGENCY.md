# P7 实际PCM可视化与应急模式

2026-10-28。同一主工程增量集成，硬件/构建/用户确认范围以p7_validation.json为准。未增加处理器，未改音量范围或输出增益。

## 实际音频可视化

输入直接接HDMI使用的aw[0]/aw[1]：已经过音源选择、音量、暂停及静音处理。正常WAV、测试音、应急提示音和静音均反映真实输出，不使用动画或预制波形。图形支路只旁路观察，从不反压或减慢音频。

- 128点左声道波形，每16对采样抽取1点；48kHz下覆盖约42.7ms。完成整页后在垂直消隐交换前后页，禁止边写边显示产生撕裂。波形为线性采样示意，有降采样混叠，不作为测量频谱；未实现FFT。
- 左/右声道每帧绝对峰值电平，5位线性相对幅度（非dB、非RMS），绿色左声道、橙色右声道，白色峰值标记逐帧衰减。
- 处理-32768绝对值和满幅饱和。静音/暂停后电平在下一帧归零，波形下一页变为中线，峰值约半秒衰减。
- 使用额外一个小块RAM。画面底部PCM WAVEFORM区域显示，文件菜单、字幕和图像缩放/转场保留。

## 拨码位置

板卡丝印是引脚号：A11=SW3（从右数第4个），A12=SW4（从右数第5个）。向板内为高，向板卡边缘为低。最右A9=SW0，高运行/低复位，不作应急键。

| 控件 | 行为 |
|---|---|
| A11/SW3高 | 进入应急模式 |
| A11/SW3低 | 退出物理应急；如果软件Q锁存仍在则需X退出 |
| A12/SW4低 | 正常显示可视化（默认软件使能） |
| A12/SW4高 | 隐藏可视化，不改变声音 |
| 开发命令Q / X | 软件进入/退出应急；物理高电平优先，X不能越过A11高电平 |
| 开发命令Z | 软件切换可视化；A12高电平仍强制隐藏 |

原16键功能不改。模式在帧边界提交，OSD状态采样可能再延迟一帧。拨码同步进入FPGA，未使用外部控制器。

## 应急场景与优先级

应急页面为FPGA实时生成的红色提示页，显示EMERGENCY NOTICE、疏散/保持出口畅通等英文提示和专用应急滚动字幕。没有依赖TF中预制的应急图像。

1. 正常WAV消费暂停并保留FIFO/播放位置，SD读卡上下文保留；背景图片调度继续，保持存储与视频刷新，退出时返回当前轮播画面。
2. 改由现有硬件1kHz正弦源输出约0.5秒响/0.5秒静音提示，采样仍48kHz并从同一HDMI输出。应急音量走现有0～8档，峰值不高于原测试音。
3. 静音KEY3仍有效，保持用户原有静音/音量。正常WAV暂停状态也保留；应急提示音优先于正常播放暂停，停止提示音用KEY3静音或退出应急。
4. 退出恢复原音源、播放/暂停、静音和音量状态；正常播放状态下WAV从保留位置继续，不重新挂载TF卡或复位SDRAM。应急期间若用户主动改变播放设置，按其新设置生效。
5. A11高电平优先于软件退出。没有自动真实灾情检测；这是手动触发的展示/应急发布模式。

## 模块与诊断

- rtl/system/dmz_audio_visual.sv：实际PCM采样、双页波形、左右电平/峰值、同步像素叠加。
- rtl/system/dmz_scene_control.sv：拨码同步、软件控制、帧边界模式和提示音节奏。
- 顶层音频选择在音量前切换应急源，音量/静音后同一PCM同时送HDMI与可视化；应急背景位于图片参数之后，提示文字不受亮度/对比度影响。
- T1ST仍v4/96字节：word22新增bit27应急、bit26可视化；word14原保留低8位新增左右电平各4位（5位内部值右移1），命令字节/命令计数位置不变。

## 验证

- test_scene_visual.ps1：帧边界切换、物理优先、提示节奏、-32768极值、声道独立、电平/峰值、真实波形页、静音/衰减、关闭透明。
- test_osd_menu.ps1：保留菜单/文字栅格回归，另输出应急页预览；预览是仿真产物，不冒充实拍。
- test_p7_board.ps1：实际HDMI非零PCM与静音计数、静音电平归零、应急时WAV位置保持且有提示音数据、应急静音、退出后WAV继续、可视化开关及错误检查。结束正常有声轮播。
- 用户仍需分别确认真实波形/电平变化和A11应急进入/退出显示与听音；仿真与串口证据不能代替这两项。
