# P2：SDRAM 与双帧缓存

日期：2026-10-26。用户已授权暂时跳过声音实测，继续 P2；板卡和显示屏已重新连接。P1 音频待验收状态保留。

## 实现
- 使用 EG4S20 封装内的 EM638325，8 MiB，4 bank × 2048 row × 256 column × 32 bit；实例化 `EG_PHY_SDRAM_2M_32`，没有额外处理器。
- 自编 SDRAM 控制器：200 µs 初始化等待、全 bank 预充电、8 次初始刷新、模式寄存器设置；CL3、顺序 BL8、自动预充电。
- 50 MHz 控制器时钟，50 MHz/180° SDRAM 时钟；返回数据在控制器下降沿先采样，再在上升沿组包。PLL 同时输出 25/125 MHz 视频时钟。
- 运行中约每 7.8 µs 提交刷新请求，最多推迟一个在途事务；刷新优先于新事务，显示读取优先于后台写入。
- 上电破坏性全容量自检：全零、全一、地址混合、地址混合反码；每种模式全写、在持续刷新的同时保持 100 ms、全读并逐字比较。合计核对 8,388,608 个 32 位字。
- 首个错误地址、预期值、实际值及累计错误数保留；自检失败时不进入帧缓存播放，输出红屏。
- RGB565，每个 32 位字打包两个相邻像素；两个 640×480 帧缓存分别占 614400 字节。
- 前台缓冲供显示读取，后台缓冲生成下一幅测试图；只有完整写完且进入垂直消隐期才交换。约每 60 帧交换一次，约 1 秒。
- 2048×32 bit 双时钟 FIFO，Gray 指针同步，处理 50 MHz→25 MHz 数据传输；每帧消隐时协调清空、重新预取，记录有效区欠载像素数。
- 串口 115200/8N1，每约 0.5 秒发送一次带 XOR 校验的 64 字节状态快照。

## 存储布局
| 用途 | 字节地址 | 大小 |
|---|---|---|
| 帧缓存 0 | 0x000000～0x095FFF | 614400 字节 |
| 帧缓存 1 | 0x100000～0x195FFF | 614400 字节 |
| 上电自检范围 | 0x000000～0x7FFFFF | 8 MiB |

控制器接口使用 **32 位字地址**，请求必须 8 字对齐，一次传输 256 bit；P3 加载器需打包 RGB565，并处理不足一个突发的尾部。当前不提供任意字节写掩码。

## 上板操作
- SW0 高：运行；低：复位。复位释放后重新执行全容量自检。
- 自检时深蓝背景；失败为红色；通过后显示从 SDRAM 实际读出的彩条/反色彩条、底部色阶、白边及移动白块。
- 紫色有效像素表示 FIFO 尚未就绪或欠载，应结合串口计数定位。
- P2 发送静音音频包；SW1/SW2 暂未接入 P2 控制功能。

| LED | 含义 |
|---|---|
| 0 | 心跳 |
| 1 | SDRAM 初始化完成 |
| 2 | 全容量 BIST 通过 |
| 3 | BIST 错误 |
| 4 | 帧缓存显示已启用 |
| 5 | 换帧计数最低位 |
| 6 | 曾发生有效区 FIFO 欠载 |
| 7 | 帧缓存状态机故障 |

## 仿真边界
测试模型按 SDRAM 命令解码，包含 bank/row/column、CL3/BL8、6 ns 返回延迟、预充电/刷新/激活间隔检查。它是独立行为模型，不是厂商模拟电气模型，不模拟模拟保持失效、串扰或封装温漂。
测试覆盖全容量四模式读写、刷新、首错记录、错误注入、完整像素数据链路、前台禁止写入、消隐换帧和 FIFO 欠载。仿真保持时间缩短为 100 µs，实板设置为 100 ms。
测试把换帧间隔缩短为 2 帧，检查连续 8 帧、2457600 个有效像素；实机默认 60 帧换一次。
