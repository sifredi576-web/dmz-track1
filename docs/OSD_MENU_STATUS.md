# 屏幕OSD与TF文件选择

更新：2026-10-28。本阶段在同一主工程中新增状态OSD和单文件焦点浏览菜单，所有索引、交互和像素叠加由FPGA实现。电脑仅作开发控制/诊断工具。构建、实板和用户确认结果以本文件末尾及osd_menu_validation.json为准。

## 操作

以用户提供的板卡正面图为准：

| 按键 | 位置 | 功能 |
|---|---|---|
| KEY11 | 从上往下第二排最左 | 打开/关闭文件菜单 |
| KEY15 | 最上排最左 | 浏览下一个文件 |
| KEY14 | 最上排左起第二 | 浏览上一个文件 |
| KEY13 | 最上排左起第三 | 切换BMP/WAV分类 |
| KEY12 | 最上排最右 | 确认播放屏幕上显示的文件 |
| KEY6 | 倒数第二排左起第二 | 恢复自动轮播和音频 |

菜单打开时停止自动换图，背景WAV继续。浏览候选文件不会读入新图片或切换音轨；按确认才提交，菜单随后关闭。关闭菜单保留当前图片，按KEY6恢复自动轮播。原KEY0/1、KEY2/3、KEY4/5、KEY7～KEY10控制仍保留。没有该类文件时显示NO FILES，确认无操作；查询标签尚未返回时显示READING，不允许提交旧文件名。

## 屏幕内容

- 顶部：DMZ MEDIA、当前图片/总数、音量0～8、PLAY/STOP/MUTE/NONE/FAIL、AUTO/HOLD、当前WAV/总数。
- 中部菜单：BMP/WAV分类、候选文件编号与短文件名、浏览/确认/关闭提示。
- 底部：SD/BMP/WAV错误码（十六进制）与常用按键提示。格式不支持的WAV显示FAIL和错误码，不影响正常图片显示。
- 状态在垂直消隐采样，文字白色、候选信息青色、背景变暗；不写入原始BMP，不修改音频增益或音量上限。使用英文/数字字库，暂未实现中文字库、滚动字幕、运行时间、亮度或对比度调节，不能称E1/E4全部完成。

## 支持范围

FAT16/32根目录，最多32张BMP、16个WAV，按目录扫描顺序（不排序）。显示8.3短文件名；长文件名使用其短别名，目录不递归。图片格式仍为640×480、24/32位BI_RGB；WAV仍为标准PCM48kHz/16位/双声道。仅选中的WAV循环，没有自动音轨列表播放。

显式确认WAV时，先取消旧文件字节流并排空已发SD事务；音频FIFO两域复位，元数据稳定后从新文件开头预填再发声。手动换音轨允许短暂静音；普通图片切换依然要求背景音频不中断。确认当前同一WAV也会从头播放，能够恢复已修复且经重扫的文件；TF卡内容更换仍需KEY7重扫，不宣称支持安全带电插拔。

## 实现入口

- rtl/system/dmz_file_menu.sv：浏览游标、分类、标签校验与确认提交。
- rtl/system/dmz_osd.sv：字模、文本和两周期预计算叠加；原RGB路径保持一周期延迟，屏幕坐标/HDMI有效期对齐。
- rtl/media/dmz_fat_catalog.sv：增加16项WAV元数据表和独立浏览查询端口，不干扰图片播放索引。
- rtl/media/dmz_wav_player.sv、dmz_media_storage.sv：音轨选择、旧事务排空与FIFO清空。
- rtl/system/dmz_track1_top.sv：查询/响应一致快照跨域、OSD与媒体总集成。

跨时钟命令传递改为复用dmz_pixel_fifo的4项小队列，避免旧单比特事件在紧邻命令时的保持时间不足。来源为按键与115200串口，最大突发两条；scripts/test_command_fifo.ps1以错相25/50MHz和300条连续突发命令验证顺序与数据。开发辅助串口不参与素材处理。

开发串口新增F菜单、I上一个、O下一个、V分类、E确认。图像确认命令编码0x80～0x9f，音轨确认0xc0～0xcf，仅为内部/诊断协议；板端操作不要求用户理解编码。

T1ST仍为v4/96字节，word22原低8位不变；新增31:28选中WAV索引、23目录就绪、22菜单打开、21:16候选查询（bit5为WAV分类）、15:11 WAV数量。scripts/system_console.ps1兼容解析；E的回报可能是实际索引命令而非字母E。
