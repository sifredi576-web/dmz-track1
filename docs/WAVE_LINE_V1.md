# 波形连续细化第一版

用户范围：先实现连续化和细化，保持现有显示框及波形范围；第一版上板观察后，再咨询是否在不考虑背景图的前提下放大。未授权提前执行放大。

实现：原128点、每16个PCM样本取点、左声道、帧消隐双缓冲交换不变。每个缓存项存储当前点及前一点（16位×256），一次BRAM读取取得线段端点。每4个横向像素计算四分线性插值，并绘制相邻列插值高度间的闭区间，消除陡变处断裂。浅斜率处1像素细线；陡变处为保持连通绘制短竖线，不添加模糊光晕。显示框512×64、中心线、增益/±22像素限幅、电平条及颜色保持不变。

这是显示连线，未增加真实采样细节，未实现触发稳定、抗混叠或自动增益。相邻点共享缓存宽度增加，是否增加BRAM以最终综合结果为准。

验证：test_scene_visual.ps1通过24576个像素的独立栅格参考比对（交替正负限幅、平线、斜线、采样点边界），以及真实PCM采集、静音、峰值衰减、隐藏、应急控制回归。主工程已通过布局布线及最终STA：setup +0.108ns、hold +0.023ns；LUT16244、REG8855、BRAM62、DSP20。相较交互版增加154 LUT，BRAM未增加。已下载SRAM，COM3板端识别16页、16BMP、7WAV，错误0，已进入观察页。实物线条观感等待用户反馈。
