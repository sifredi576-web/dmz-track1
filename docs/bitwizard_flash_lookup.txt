1 工具简介

   Anlogic TD 软件将原 Download 工具，升级为 BitWriter 工具；将原 Device Chain 工具，升级为
ChipLinker 工具。

   同时，推出独立于 TD 环境的 BitWizard 工具，集成 BitWriter、ChipLinker 等工具。

   在使用 BitWizard，需对原 AL-Link 工具固件进行升级，否则，可能存在稳定性问题。

                                表 1-1 名词解释

    -             名词                               说明
    1            AL-Link           在线编程器，支持 TD(TangDynasty)软件。
    2       AL-Link-Pro                           离线编程器。
    3        AL-Link-FT    在线编程器，支持 TD(TangDynasty)和 FD(FutureDynasty)软件。

3 位流文件配置与生成

    位流文件的生成，可通过 TD Properties Configuration 进行相关配置。

    Configuration 显示的是 Properties → Generate Bitstream 中的 Control Option、 Startup
Option 和 Attribute Option 的相关信息分栏显示了对应 option 的 Current Value 及 Default。

    当对其中的某个或某些 option 进行了更改并保存设置后，Current Value 会显示相应设置的
option 值。

3.5 文件格式

  在工程目录下，根据用户配置，其 best_result 文件夹中，生成文件格式如表 3-1 所示，若器件
支持位流压缩功能，则包含_compress 命名的相关配置文件。

                              表 3-1 生成文件格式

          格式                                     备注
.bit                二进制配置文件，包含头信息等。此文件通常应用于
                    BitWriter/ChipLinker，结合下载器，下载至目标器件
.bin                二进制配置文件，不包含头信息等。此文件通常应用于 BitWriter 结合下
                    载器，下载至目标器件；也可用于用户自定义配置方案；
.rbf                相较于 bin 文件格式，每四个字节为一组，按字节翻转，如下：
                    *.bin 文件：DD BB 66 22
                    *.rbf 文件：22 66 BB DD
*_byteReverse.bin   相较于 bin 文件格式，每个字节为一组，按位翻转，如下：
                    *.bin 文件：DD BB 66 22
                    *_byteReverse.bin 文件：BB DD 66 44
*.SVF               Serial Vector File，串行向量格式文件。
                    可通过 ChipLinker 工具生成。

5.6 SVF 应用场景介绍

    SVF 文件，Serial Vector Format，串行向量格式文件。使用 SVF 文件格式，无须关心位流格式，
可通过第三方编程工具，对目标器件编程。根据应用需求，可通过 ChipLinker 生成多种 SVF 文件。


5.6.1 SRAM 编程

    可通过 SVF For SRAM 界面，生成 SVF 文件，此文件可将位流下载至配置 RAM 上，掉电丢失。


5.6.2 Flash 编程

    针对 Flash 烧录，支持位流数据和用户数据烧录，可通过 SVF For Flash、SVF for User Data 界
面，生成 SVF 文件，如图 5-23 所示。




                               图 5-23 Merge SVF

    典型组合示例如下：

   rf_mode：刷新模式，此选项生成的 SVF 文件，在烧录前，将对正运行的功能（若有）进行复位，
    然后，对 Flash 进行烧录操作，烧录后，器件将从 flash 加载烧录后版本；

   bg_mode：背景模式，此选项生成的 SVF 文件，在烧录时，对正运行的功能（若有），不影响；烧录
    后，若需要加载新的版本，则需掉电，或者外部复位(programn)；

                                                  ，不影响；烧录
    bg_mode + rf_mode：此选项生成的 SVF 文件，在烧录时，对正运行的功能（若有）

   Verify：此选项将生成回读校验 Flash 数据操作，可结合 bg_mode、rf_mode 功能进行组合；在
