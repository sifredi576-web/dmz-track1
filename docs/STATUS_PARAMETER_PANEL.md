# 右侧状态与参数面板

用户调整顺序：本轮先做右侧小状态界面及赛题扩展(4)参数显示；触发稳定和左侧按钮仍未实现，等待后续单独授权。

面板固定(576,128)、64×160，观察页常驻，其他课件页仅在设置菜单打开时显示，通知及应急隐藏。与波形右边界相邻，绘制不进入x<576，不遮挡音源按钮。显示播放、暂停、静音、结束、加载、无声、错误；故障/加载优先，其次静音、暂停，无音源时显示无声，数据消费完后显示结束。全部信号来自像素域，状态按帧更新。

显示音量、亮度、对比度0～8。亮度/对比度改变后，数值及箭头高亮约2秒（120帧），刻度条同步反馈；箭头表示数值变化方向，含对比度8→0循环时的下降。显示数值来自实际生效的display_controls输出，不是独立假计数。快照可能比实际参数生效晚一帧。

操作：KEY12首次打开课件显示设置；KEY14/KEY6上下选择，KEY11/KEY9左右调整，KEY10执行；第3项恢复默认4/4；KEY8关闭菜单。在观察页关闭菜单后仍可看到右侧数值。KEY3静音/解除，KEY2暂停/恢复；这些状态不再需要通过是否有声猜测。静音不等于暂停，音轨可在静音期间继续结束。

像素叠加在亮度/对比度处理之后，面板使用固定深色背景，保证低亮度或极端对比度下仍可读。现有波形6kHz、12位幅度及512×160区域不变，无新TF文件要求。

采用离线生成的32字、14×16字模，内嵌初始化ROM，一块BRAM9K；不依赖电脑运行。当前BRAM64/64，后续触发按钮应复用现有SCENE图层及资源，避免再增加独立字库。字体数据assets/status_panel_font.json，参考图docs/materials/status_panel_reference.png不是实拍。

验证：test_status_panel.ps1校验122880个像素，覆盖所有状态、参数值、箭头、刻度、120帧提示到期、默认值、帧一致性、边界及关闭。主工程setup +1.792ns、hold +0.030ns，LUT16553、REG8888、BRAM64、DSP20，已下载SRAM。用户已确认文字和播放/结束/静音/暂停正常；用户另确认“调节、数值、变化提示及恢复默认均正常”，本项已验收。最终音量5/8，为用户操作保留；非静音/非暂停，菜单已关闭。触发稳定仍待另行授权。证据status_panel_validation.json。
