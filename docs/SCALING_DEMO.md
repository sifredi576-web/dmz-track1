|---|---|---|---|

导航按钮独立叠加；横图按钮放在下方留边，竖图按钮放在两侧留边，小图底部留有按钮空间。顶部滚动字幕继续保留。图中文字与图形为离线教学素材，运行时图片尺寸适配由FPGA执行；声音示意线不是实际PCM波形。

## 更新方法

1. 已有声音课件TF卡：将本目录TF_UPDATE内的4个文件复制到卡根目录，替换SCENE.BIN并新增三张BMP。原音频和其他图片无需重拷。
2. 新卡可使用tf目录的完整包；PACKAGE.json是电脑端说明。
3. 加载本目录dmz_track1.bit。旧位流默认仍可能等待KEY2启动，因此新配置需与本轮位流配套。
4. 启动后应先看到WIDE01横图，随后自动显示竖图、小图和原课程，最终停在第一题。KEY2可暂停/恢复轮播。
