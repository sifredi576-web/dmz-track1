# WAV 解码模块记录

2026-10-28更新：本模块已接入共享FAT/SD、音频FIFO和HDMI，实卡WAV播放与图片联动已通过，用户确认声音连续。当前状态以 `AV_INTEGRATION_STATUS.md` 为准；以下为独立模块阶段的历史记录。

2026-10-27：已新增 `rtl/media/dmz_wav_decoder.sv`，并完成21个离线测试；尚未加入统一工程位流，没有实板WAV播放或音画同步结论。

模块接受文件字节流的ready/valid接口，输出32位立体声PCM对，低16位左声道、高16位右声道。输出阻塞时保持数据；由后续音频FIFO和48kHz输出节拍消费，模块自身不产生播放时钟。start可重新开始解析；上游读卡/文件错误通过stream_error中止。

当前格式：RIFF/WAVE、小端、PCM=1、48000Hz、16位、双声道、block_align=4、byte_rate=192000，fmt必须在data之前。可跳过未知块和奇数字节填充，接受fmt附加字段，按data长度结束；数据后额外内容不参与播放。不支持压缩、浮点、单声道、其他采样率或位深，明确拒绝。

测试入口：`scripts/test_wav.ps1`；结果：`docs/wav_sim_result.txt`。正常数据逐个核对有正负值的左右声道，所有用例施加源端间歇和输出FIFO阻塞。覆盖基本流、JUNK奇数填充、fmt18、尾部附加数据、解析中重启；错误魔数、过短文件/头、RIFF/块长度溢出、短fmt、浮点、单声道、错误采样率/对齐/位深、缺data/fmt、空或非整采样data、读错误。

错误码：1魔数；2RIFF文件长度；3不支持fmt；4块越界/缺data；6 data前无有效fmt；7空或非4字节对齐data；0x80|上游错误表示流中止。

下一步依赖M1共享文件服务：提供带错误和停止机制的WAV字节流，接入音频异步FIFO、音频优先SD仲裁，再替换统一工程中的测试音源。还需综合/时序、实际WAV文件、持续听音和加载图片不断音的验证。字节流停止但不报告错误时，模块会等待上游；超时/真实EOF错误应由文件服务报告，不能宣称已覆盖未接入文件服务的故障。
