# 运行时间、滚动字幕和图像参数

2026-10-28。在既有OSD/文件菜单主工程中增量实现；本轮不改音量范围、音频增益或显示器设置。

## 板端操作

关闭文件菜单（KEY11）后，最上排从左到右：KEY15亮度加、KEY14亮度减、KEY13对比度循环、KEY12恢复亮度/对比度默认。打开菜单后这四键仍分别是下一项、上一项、分类、确认，不调图像参数。原播放/音量按键保留。

亮度/对比度显示为0～8档，默认均4。亮度相对原图偏移-64～+64，每档16；对比度增益为档位/4（0～2倍），以128为中心。各RGB通道采用((像素-128)*对比度档位算术右移2)+128+(亮度档位-4)*16，再饱和至0～255。默认严格等于原图；0对比度为平灰，这是预期行为。参数在垂直消隐应用，不修改TF文件或SDRAM原图；OSD文字保持清晰、不跟随图片参数变暗。

## 显示

- UPTIME HH:MM:SS为FPGA上电/复位后的运行时间，使用25MHz时钟计秒，100小时回绕。没有RTC，不是实际日期时间。媒体重扫R不重置计时或图像参数，SW0复位/重新下载会重置。
- 图像参数行显示BRI和CON档位；英文字幕在底部错误码上方按每帧1像素左移，约59.5像素/秒，1024像素循环。字符为板内ROM资源，滚动与叠加在FPGA内实现。
- 字幕内容为DMZ FPGA MEDIA / TF CARD AUDIO AND PICTURES / WELCOME；当前固定标语，尚不支持TF文本文件或中文动态字幕。
