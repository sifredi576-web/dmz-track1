# 波形放大观察版V2

用户观察V1后反馈：声音正常、效果较好，纯音峰值部分仍有连续性不足和像素堆叠。随后明确同意先放大显示框和波形，再优化峰值。

本版显示框保持宽512，位置(64,128)，高度64→160，结束于y288；音源按钮从y304开始，未改变按钮和返回/答题布局。此为忽略背景图的固定坐标观察版，暂不使用SCENE.BIN中的波形坐标，不要求重拷TF素材。

波形中心y200，满幅显示约±64像素，替代旧±22像素限幅。旧的sample>>2再clamp22会使部分高峰被压平，本版sample幅值/2覆盖整个8位采样范围，减少显示人为削顶。仅改变显示增益，不改变实际音量和PCM输出。

每列线段绘制起点、不重复绘制终点（平段保留单点），保持8邻域连续并减少峰值交接处的重复像素。缓存、128采样点、16倍抽取、双缓冲和峰值电平保持原样；未增加触发、抗混叠或曲线拟合，仍可能看到采样折线。

73728像素独立参考栅格比较通过，涵盖满幅正负交替、平段和采样边界，PCM、静音、峰值衰减、关闭和通知控制回归通过。主工程构建与时序已通过，setup +1.829ns、hold +0.086ns，LUT16250、REG8815、BRAM62、DSP20。已下载SRAM并进入观察页，板端错误0。新版观感等待用户反馈。
