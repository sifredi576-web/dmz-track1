# 可配置交互多媒体平台

当前zyr已迁入main 28298f7功能，初步验证与未完成项见[迁移记录](MAIN_MIGRATION.md)。历史主分支实板结果不作为本轮位流验收结果。

## 使用与资源

- 主工程：project/td/dmz_track1.al，整机顶层：dmz_track1_top。
- 声音课件：assets/platform/tf_course_v2；另一套公告配置：assets/platform/tf_notice_v2。
- 将所选包SCENE.BIN、BMP、WAV复制到FAT16/FAT32 TF根目录，同卡只使用一份SCENE.BIN，不更改生成名称。PACKAGE.json及独立UI文件用于核查，按钮像素已嵌入SCENE.BIN。
- 课程16页、三段讲解、三种观察音源、三道单选题、解析/结果、普通/优先通知。先选择答案再提交，首次计分，返回不重复计分，重新学习才清空。
- 图像转场提交后启动配置音轨，以实际FIFO消费样本判断播放完成。通知可保存页面、焦点和原音频位置；物理应急有效时不能用退出键解除。
- 缺少SCENE.BIN时回退图库；无效CRC/语义不激活配置。重扫会重置课程状态，不等于暂停。保持SRAM下载方式；本轮没有操作板卡。

## 协议与实现边界

v2为32字节头、32字节资源/页面/控件记录与32字节对齐A1R5G5B5贴图，CRC32覆盖载荷。支持64资源、32页、128控件、每页8控件、4层、1MiB配置载荷。贴图为二值透明；最大272×64。媒体仍为最多32张BMP/16个WAV，HDMI 640×480、PCM 48kHz/16位双声道。

帧缓存字节地址0与0x100000；配置区0x200000～0x2FFFFF，对控制器的32位字基址为0x080000。视频优先内存仲裁、响应归属、请求排空及跨时钟握手沿用来源实现。

音频FIFO为2048对样本，约42.7ms。目录名称/长度分时读BRAM，OSD文本和字体同步BRAM，波形/BMP/FIFO采用来源的可逆物理地址重编码。默认FULL_TELEMETRY=0为32字节v5；设1为96字节v4，仅用于需要的完整诊断，资源需另核。

离线打包：`python scripts/assets/pack_platform.py <源JSON> --materials <素材目录> --output <新目录>`；源PNG/SVG不全在仓库中，已发布TF包完整保留。原稿准备和重新打包不会由板端运行流程调用。
