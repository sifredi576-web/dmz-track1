# 项目最终目标与实施边界

确认日期：2026-11-01。依据：用户明确确认最终目标及本次要求。本文是当前有效目标，优先于旧文档中的校园公告终端、固定教学终端或其他历史定位。目标声明不代表功能已经实现。

## 最终定位

基于FPGA的可配置交互多媒体演示平台，以“声音与音色”教学课件展示能力。

“声音与音色”是平台的首个示范资源包，不是写死在底层媒体逻辑中的唯一用途。平台通过TF卡上的资源和配置描述页面、图层、控件、跳转与播放行为；在支持能力与资源上限内，更换课件内容、控件布局和动作配置不需要重新编译或下载FPGA程序。

## 必须实现的平台能力

- 复用DMZ_EG4S20统一主工程及现有TF/FAT、BMP、WAV、SDRAM、缩放、转场、HDMI、参数OSD和实际PCM可视化。
- 将页面内容、控件布局和动作映射与媒体底层分离。配置描述资源标识、图层顺序、位置尺寸、可见/可用状态、导航关系和动作，不依赖文件复制顺序。
- 支持背景、有限数量的前景贴图、按钮、标签和动态OSD组合；明确层数、缓存、素材尺寸等上限，不承诺任意数量全屏透明图层。
- 板载按键驱动焦点导航、确认、返回及页面快捷操作。按键绑定语义动作，不依赖背景像素；同一按键在当前状态只能执行一个动作。
- 支持页面跳转、音轨选择、暂停/静音/音量及约定的自动推进。定义图像提交与音频启动边界，实测前不能宣称严格同步。
- 对缺文件、非法配置、越界布局、无效跳转及不支持格式给出可恢复处理，不错误播放其他资源。
- 使用另一份简短公告或展陈配置证明泛化：同一FPGA位流，仅更换或选择TF配置即可改变内容和交互流程。

## 首个示范课件

课程封面、图文学习、纯音/钢琴/人声观察、三道单选题、解析、首次作答计分和总结。普通/优先通知作为插播组件，定义优先级、过期请求取消和返回上下文。课堂题目、资源与流程由配置或明确的通用组件接口组织，不向TF/HDMI底层写入课程专用判断。完整能力分阶段交付。

声音观察来自预制TF样本，不新增麦克风；波形为实际PCM观察显示，不冒称精密频率或音色测量。教学素材须保证结论准确。

## 素材约定

- 背景图、通用按钮底图和中文标签独立制作。选中、按下、禁用、分数、页码及实际波形由FPGA动态叠加。
- 先保留高分辨率/可编辑原稿与透明PNG。背景首版导出640×480的24位未压缩BMP；按钮资源由后续加载协议统一转换打包，不把所有UI小图混入现有图库。
- 首套教学界面的顶部/底部留白为模板约定，不是平台永久固定布局。主体课件可先将中文正文制作进背景，后续扩展字库与文本组件。
- 音频保持PCM WAV、48kHz、16位、小端、双声道；资源绑定使用明确名称/标识，不依赖长文件名短别名自动相同。

## 运行与实施边界

- 所有运行时配置解析、调度、按键、答题、绘制和音视频处理在FPGA实现，不搭配额外处理器。电脑可离线制作和打包课件，开发时编译/下载/诊断，运行时不提供媒体处理或必要控制。
- 首版保持现有640×480输出。用户屏幕15.6英寸，不等于已确认原生分辨率；提高输出分辨率须单独评估时钟、带宽、缓存和时序。
- 不直接解析PPTX；“类似PPT”指页面组合、跳转和媒体交互。编辑器可后续开发，首版允许受约束的配置文件制作方式。
- 暂不承诺复杂自由动画、视频解码、任意缩放混合、全中文字符集或自动音色识别。
- 用户于2026-11-01追加最终交付要求：完成板载Flash固化与掉电后自动启动。这是用户要求的工程交付项，不是所提供赛题原文的明确强制条款。当前仍为SRAM配置，断电后需重下载；Flash固化与冷启动均待实现和实板验收。
- 提交演示视频不超过三分钟；完整交互流程不强制压缩到三分钟。视频优先展示平台组合、教学闭环、实际音画与可视化、插播恢复和配置泛化；脚本按约2分45秒设计，预留余量。

## 实施与验收

1. 核对当前基线、配置协议、资源标识及容量预算。
2. 实现资源查找、页面描述、控件/图层与动作引擎，先完成两种配置切换。
3. 实现声音课件、单次音频完成事件、答题计分和插播恢复。
4. 完善界面、素材、异常处理及三分钟演示。
5. 功能与时序稳定后，核对板载Flash型号、配置模式、下载流程和恢复方法，执行固化；断开下载/串口控制，使用电源（允许电脑仅供电）、TF卡和显示设备，真实断电再上电，确认自动加载并进入默认演示或课件入口，板载交互和音画正常。不能用SRAM下载、软件复位或文档声明代替冷启动验收。课件更换仍应只更新TF资源/配置，不要求每次重刷Flash。

每阶段区分已编码、仿真通过、构建/时序通过、实板通过和用户确认；只做受改动影响的必要验证，不重复无关长测，不放宽时序约束。平台配置化、按钮贴图和课程组件目前属于待开发目标，不能套用旧媒体工程实物验收结论。
