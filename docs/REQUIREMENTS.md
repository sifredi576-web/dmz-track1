# 当前范围与能力边界

保留赛道一多媒体展示系统及五项扩展的现有成果，所有运行时解析、控制及处理在FPGA内完成。应用为校园展示与应急广播终端。当前不追加Flash固化和非易失冷启动要求。

- FAT16/32根目录、8.3文件名，最多32张BMP、16个WAV。
- BMP宽1～1920、高1～1080，24/32位BI_RGB，等比最近邻缩放、居中留边；HDMI固定640×480约59.524Hz。
- WAV为PCM48kHz/16位/双声道；当前选轨循环，手动切轨允许短暂静音，切图保持音频连续。
- 板载菜单/暂停/静音/音量；字幕与运行时间、亮度/对比度OSD、20帧擦除、实际PCM波形/电平及应急进入退出。
- 保持现有音频增益和音量范围。只下载SRAM，不自动操作板卡。

逐像素测试和实板记录分别说明范围；模拟通过不能代替显示/听音确认。真实多音轨切换、A12高电平隐藏等未完整实测项不补写为通过。整理只改变组织和入口，不主动改变现有功能。
