# 需求与演示对应

选题一采用单板EG4S20，以声音课程为完整应用。是否通过以实际记录为准，已有算法不等于当前演示充分体现。

| 条款 | 当前实现/演示 |
|---|---|
| 基础1：完整性 | TF课件、图文讲解、声音观察、答题计分、通知返回 |
| 基础2：稳定与鲁棒 | 异常配置校验、帧缓存、音频FIFO；当前版本仍需持续实板复核 |
| 基础3：音频 | HDMI输出讲解与三种样本，暂停、静音、音量 |
| 基础4：工程规范 | 唯一工程、明确输入、约束、源码、构建和当前验证摘要 |
| 扩展1：叠加与字幕 | 控件/焦点/分数、旧OSD；课件独立底栏待补 |
| 扩展2：轮播与转场 | 擦除转场已有；待机自动轮播待启用配置 |
| 扩展3：缩放 | 最近邻等比适配/居中留边已有；当前BMP均640×480，需新增横竖实验图体现 |
| 扩展4：参数与OSD | 设置菜单显示亮度/对比度并调整实际画面 |
| 扩展5：可视化 | 实际输出PCM波形、声道电平，无FFT频谱 |

BMP范围为24/32位未压缩、1～1920×1～1080，HDMI为640×480。WAV为PCM48kHz/16位/双声道。最多32张BMP、16个WAV，场景最多64资源、32页、128控件；UI每张最大272×64，每页最多8控件。

后续补齐安排见[演示方案](demo_plan.md)。完整演示不替代稳定性测试；PC预览不作为FPGA截图；未上板的位流不标记为实板验收通过。
