# 需求与实现对应

依据选题一1.3、1.4、1.5。平台为单板EG4S20BG256，运行中的算法、数据处理和控制在FPGA实现；电脑只用于离线制作资源、开发和诊断，不参与播放循环。

| 条款 | 当前实现 | 本轮证据 |
|---|---|---|
| 基础1：核心功能完整性 | TF课件、图文/声音、自动演示、答题计分、通知与返回 | 主分支源码/资源对齐、课程流程和UI仿真 |
| 基础2：稳定性与鲁棒性 | CRC与格式校验、双帧、FIFO、SDRAM刷新、异常回退 | 两帧供数仿真、FIFO边界；最终时序与实板限制见验证记录 |
| 基础3：基础音频 | HDMI PCM输出、讲解和三种音源、音量/静音/暂停 | 音频消费完成及48kHz采样检查；本轮未听测 |
| 基础4：工程规范 | 单工程/输入清单、约束、单份素材、直接测试、交付哈希 | 结构检查及构建清单 |
| 扩展1：图层/字幕 | 控件/焦点/答案/成绩、中文状态栏、顶部平滑循环字幕 | 字幕完整栅格与回绕仿真；图层/侧栏与main源码对齐 |
| 扩展2：轮播/转场 | 可暂停的课程自动演示、10步擦除切换 | 19页配置、自动流程/菜单保护仿真；转场视觉需上板 |
| 扩展3：自适应缩放 | 1280×720、360×640、320×240实际BMP，等比最近邻和黑边 | 资源字节对齐；四组逐像素解码检查 |
| 扩展4：参数/OSD | 音量、亮度、对比度调节，侧栏数值和变化提示 | 与main功能源码对齐；人机显示效果需上板确认 |
| 扩展5：音频可视化 | 实际输出PCM波形、左右电平和峰值、上升过零触发 | 周期波形重复相位、静音超时采集及自由运行切换仿真 |

格式范围：未压缩BMP24/32位、1～1920×1～1080；PCM WAV 48kHz/16位双声道。最多32张BMP、16个WAV；场景最多64资源、32页、128控件，每页最多8控件，UI最大272×64。

五项扩展均有对应实现，不能据此宣称本轮完成了实板显示稳定性、HDMI兼容性或音质验收。没有实现FFT频谱、任意矩形缩放或电脑端运行时算法。输出是75MHz自定义约60.606Hz宽屏时序，不是精确74.25MHz的标准720p60。具体证据见[技术报告](TECHNICAL_REPORT.md)。
