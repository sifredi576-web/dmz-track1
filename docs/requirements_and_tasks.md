# 赛道一要求与任务总表

依据：用户提供的赛题 1.2～1.6 原文。日期：2026-10-25。
硬件确定为 DMZ_EG4S20；不开展参赛资格讨论。

## 原文要求与本项目方案的区分
原文要求有明确应用场景的 FPGA 多媒体展示系统，体现并行处理、实时控制、低延迟显示、音画同步与多源融合，稳定运行并具备现场演示效果。算法、控制和数据处理在 FPGA 中实现，不依赖额外处理器辅助运行。
原文列举 BMP、资源扫描、SDRAM、HDMI 等技术示例，并非规定所有示例都是逐项强制项。本项目选择 SD/FAT32/BMP/SDRAM/HDMI/WAV 作为完整实施路线。
原文基础评价四方面：核心功能完整性、显示稳定性与鲁棒性、基础音频输出、系统工程规范性。
分辨率、文件格式范围、测试时长为本项目自定验收规格，不冒充原文数值要求。

## 基础目标
1. 应用：校园信息展示与应急广播终端，正常轮播和应急图文/提示音两种模式。
2. 存储：SD 卡 SPI 只读；FAT32 根目录/8.3 文件名优先，支持跨簇文件，设置超时与错误处理。
3. 图像：24 位未压缩 BMP，校验文件头、尺寸、偏移、行补齐、BGR 顺序、上下方向；越界或不支持格式明确拒绝。
4. 缓冲：8 MiB 合封 SDRAM，RGB565 双缓冲；完整帧加载后在垂直边界提交，禁止覆盖正在显示的帧。
5. 视频：640×480 约60Hz 起步，720p 在资源与时序验证后提升；无撕裂、黑闪和持续欠载。
6. 音频：先 FPGA 测试音，再 WAV PCM 48kHz/16位/双声道；由同一根 HDMI 输出视频与声音。
7. 音画调度：统一播放时间基准、FIFO 水位调度、图片预加载，明确定义暂停、切图、切音轨的行为。
8. 交互：上一张、下一张、自动轮播、暂停、静音、音量、显示参数。
9. 工程：可重建工程、引脚与时钟约束、模块仿真、时序报告、异常处理、板级验收记录。

## P1 开始前的物理信息
- 当前连接的 HDMI 接口属于哪块扩展板，是否为资料中的微处理器综合底板。
- SD 卡插槽属于哪块扩展板，是否已插卡。
- HDMI 显示器/电视及声音输出路径是否已接好。
USB/JTAG 枚举无法确认这些物理连接。确认前只推进不依赖该信息的逻辑与仿真。

## 验收原则
每项分别记录：已编码、仿真通过、布局布线通过、上板通过。只采用真实测试结果。
仅视频 TMDS/DVI 兼容输出不算 HDMI 音频完成；板载 PWM/外置声卡不能替代主方案的 HDMI 声音。
当前 P0 串口为比特级回环，不是命令解析器；矩阵键盘扫描与消抖安排在交互阶段。
