# 图片与音频配对播放

## 配对播放开发版本（2026-10-31，待实板验证）

当前源码增加图片/音轨配对；不能将此前P7实物验收结论用于本次新增功能。默认仍是背景音乐模式。KEY10（开发命令W）现在切换配对模式并恢复WAV音源；再次按下返回背景模式，当前音轨继续播放。菜单明确选择任意WAV也退出配对模式。复位/重扫后默认背景模式。屏幕尚无配对模式专用指示，操作时需记录当前模式。

配对使用FAT目录8字节短主文件名完全一致，建议大写：PIC01.BMP对应PIC01.WAV，两个文件放TF根目录；不是按目录索引或DEMO固定命名关联。最多16音轨可配对，超出范围或无同名WAV时保留原音轨。图片加载失败、不提交新画面时不切音轨。相同音轨再次提交也从头重播。

切换基准是新图片转场完成的帧提交计数，等待目录匹配稳定后重启音轨，排空旧读卡事务并刷新音频FIFO，再预缓冲播放。因此是画面提交驱动音轨切换，允许读卡/预缓冲短暂延迟和短静音；不是新画面与首音频采样同时呈现的严格同步。转场期间原音轨继续。自动轮播仍按既有图片驻留时间，不按音轨时长推进。应急/暂停/静音仍优先约束最终输出。

只做软件验证、整机构建和时序检查，不连接/下载板卡。新增控制器rtl/media/dmz_pair_control.sv；目录串行查找同名WAV避免16路并行比较；同一顶层集成。验证脚本scripts/test_pair.ps1和scripts/test_media.ps1（含+multiwav +paired，真实FAT模型、配对查找、提交前不切音轨、双向切换及精确PCM比较）。最新结果以docs/paired_validation.json为准。releases/p7_20261028仍是此前已实物验证的回退，不是新增功能版本。
