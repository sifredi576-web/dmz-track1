## 键位

按板卡正面、USB在右侧方向：

```text
KEY15 主页      KEY14 上       KEY13 重播      KEY12 资源/设置
KEY11 左        KEY10 确认     KEY9 右         KEY8 返回
KEY7 普通通知   KEY6 下        KEY5 优先通知   KEY4 结束插播
KEY3 静音       KEY2 暂停/继续 KEY1 音量减     KEY0 音量加
```

普通通知、课程主页/返回/确认及方向焦点必须等整机课件激活后生效。当前媒体兼容模式中，KEY15只选择图库第一张图（不是清除学习记录），KEY13重播当前WAV；KEY5/4使用已有软件应急进入/退出。A11物理高仍优先，KEY4不能越过物理开关；A9运行/复位、A12可视化显示/隐藏保持。

## 当前可用的资源/设置菜单

KEY12打开菜单；已打开时再次按KEY12循环：图片 → WAV → 显示 → 系统 → 图片。KEY8关闭。KEY14/KEY6上/下移动。

- 图片/WAV页：上下浏览，KEY10确认当前文件；左右切换页签。文件名元数据必须回传且查询标签一致才允许选择。
- 显示页：上下选择亮度、对比度、恢复默认；左右减/加，KEY10执行增加/循环或恢复4/4。光标移动本身不改参数。对比度0～8循环；亮度0～8饱和。实际参数仍在帧消隐应用。
- 系统页：上下选择配对模式、重扫TF、恢复自动播放，KEY10执行。模式和重扫/自动播放执行后关闭菜单。模式选择保留既有W命令行为，会选择WAV并恢复声音；音量档位/增益不提高。
- 菜单打开时，方向/确认不同时进入课件事件通道。普通通知键不执行；优先键仍可进入已有应急模式并关闭菜单。

当前图库仍可通过资源菜单选择具体图片，不能继续按旧KEY0/KEY1当作切图键。旧KEY10配对切换改到系统菜单；开发命令W仍可切换。

## 通用交互内核接口与规则

dmz_ui_keys在像素时钟域输出两条互斥通道：command用于已有播放/菜单控制，ui_action用于平台语义事件。UART优先，单个碰撞实体事件排队；原矩阵模块负责消抖、不连发和鬼键锁定。

ui_action：1上、2下、3左、4右、5确认、6返回、7主页、8重播、10普通通知、11优先通知、12结束插播。普通页面动作来自配置，不读取背景像素。

dmz_ui_controller使用已提交页面的描述符：控件数量、可见/可用掩码、四向邻居、当前控件动作、跳转/音频资源、返回页及题目元数据。

- 最多8控件；跳过不可用控件，一次移动最多检查8步，错误邻居或全禁用环不会卡死。
- 页面请求保持到适配器accept，页面到达page_loaded后才更新current_page及焦点，并请求本页音频。音频资源请求与控制请求也保持到accept，不假定一次脉冲必被接收。
- 忙时不执行普通确认/跳页，避免拿旧描述符操作新页。通知事件仍可发出；通知管理器负责后续实际抢占、取消旧请求及上下文恢复，不能把此接口当成已完成插播。
- 选项动作3只改变暂选答案；提交动作9才首次计分并跳到解析。未选择不能提交；已提交答案锁定，重复提交不加分。
- 主页/返回保留学习记录。重新学习动作清空记录并回入口。课件有3题，内核预留8个题目槽，score为答对题数，结果页分数绘制尚未接入。
- 配置失效清空控制状态；非法跳转/音频ID、禁用控件及错误动作返回错误，不错播另一个资源。
- 课件资源ID仍需由名称查找适配器解析成真实目录索引；不能直接将资源ID发给已有图库/音轨模块。

## 重播与设置命令

J新增为重播当前WAV：主工程在内存域发同音轨重启请求，保留配对模式；像素控制恢复音频播放但保留静音、音量和增益。不同于W切换配对模式并恢复声音。

显示菜单内部左/右码为{、}，文件菜单将其翻译为具体参数命令；c为对比度向下循环，C向上。串口脚本增加J及设置确认的实际命令回执别名。CLI快捷方式：project.ps1 -Action Replay。

## 本批时序修正

音频FIFO曾出现写地址到BRAM的-0.004ns保持违例。仅为音频实例开启可逆地址重编码：先做限定地址宽度的Gray映射，再将最低Gray位异或到最高位。写与读使用相同的一一映射，不改变外部顺序、指针、容量、满空或Gray CDC；其他FIFO默认保持原地址。约束未放宽。

仿真使用实际4096深度，与原FIFO和独立数据序列同时比较，覆盖满写拒绝、空读、异步时钟、随机停顿、多次回绕、复位重填。最终时序结果以ui_keys_validation.json为准；不能只凭仿真判定保持违例已修好。
